# Data and code availability

## Data availability

The study used US NCHS mortality data, Brazilian SIM/DATASUS mortality data, population data from the US Census Bureau and IBGE, WHO standard population weights reproduced by SEER, and DANE's Colombian 2023 vital statistics. Provider access routes, periods and versions are recorded in [SOURCE_REGISTRY.csv](SOURCE_REGISTRY.csv). These data and the derived research datasets are not distributed in this code-only repository. Source-specific access and use conditions apply.

Input preparation and exact historical input requirements are documented in [EXTERNAL_INPUTS.md](EXTERNAL_INPUTS.md) and [DATA_ACQUISITION_CONTRACT.md](DATA_ACQUISITION_CONTRACT.md). The derived aggregate candidate remains local pending its separate redistribution/disclosure review. This describes current repository contents, not an open deposit of all supporting data.

## Code availability

Analysis and figure-generation code, environment specifications and input-preparation instructions are publicly available at https://github.com/FENG1567/us-brazil-biliary-mortality-code (version v1.0.0-code-only). Original code is licensed under the MIT License. This code-only release does not redistribute mortality records or study datasets; reproducing the analyses requires the external inputs specified in the repository, subject to the originating providers' access and use conditions.

No archival DOI or article DOI has been assigned by this release task.
