# Code-only licence and external data conditions

The inherited MIT `LICENSE` applies to original code/documentation. This export
contains code, tests and descriptive metadata, not research-result CSVs,
population input CSVs, figure PDFs, death records or joint-pattern payloads.
The metadata catalogs name datasets but do not contain those datasets.

MIT does not relicense any NCHS, SIM/DATASUS, IBGE, Census, DANE or other
third-party data that a reader later obtains. Follow the originating provider's
conditions and preserve source attribution/version information.

The separate **complete local candidate** retains exact aggregate results for
reproduction. Some of its files have 1–9 count cells, and earlier project notes
about small-cell disclosure conflict with later packaging. No authoritative
source-specific determination settling that conflict was found locally. This
is not a blanket claim that all NCHS PUF-derived small counts are prohibited,
and CDC WONDER query rules must not automatically be applied to separately
processed public-use records. The companion-file review inventory is
`docs/data_release_review.csv`; it does not mean those data are in this export.

Before adding any such data to this code repository, confirm source-specific
redistribution/disclosure conditions. Do not silently replace real counts with
zeros or invent permissions. If data cannot be shared, retain a precise lawful
access/rebuild route and describe the reproduction limits accurately.

No raw mortality, retained death records, fine pattern/cache inputs, account
credentials, private server controllers or internal reviewer correspondence
are included. Abandoned DataFirst/ICPSR/SIA/SIH pilot downloads are not part of
the current manuscript's repository.
